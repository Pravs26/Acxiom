# AcxiomCRM – Customer Relationship Management System

## About the Project

AcxiomCRM is a simple web-based Customer Relationship Management application developed using Python, Flask, SQLite, HTML, and CSS.

The main purpose of this project is to manage customer information and track potential customers through a centralized dashboard.

## Features

- **Dashboard:** Displays the total number of customers and leads.
- **Customer Management:** Add, view, and delete customer details such as name, email, phone number, and company.
- **Lead Management:** Add, view, and delete leads while maintaining their source and status.
- **Database Management:** Stores customer and lead information using SQLite.
- **User Interface:** Provides a simple and user-friendly interface for managing records.

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS

## Project Objective

The objective of AcxiomCRM is to simplify customer and lead management while demonstrating basic web development, database integration, and CRUD operations.
